# Bitácora de Prompts

Este archivo registra los prompts utilizados con Claude Code durante el desarrollo del proyecto, junto con el contexto y resultado de cada uno.

## Formato de cada entrada

- **Fecha**
- **Contexto:** qué problema se quería resolver
- **Prompt usado:** el texto enviado a Claude Code
- **Resultado:** qué generó / si funcionó / qué se ajustó
- **Commit asociado:** hash del commit relacionado
